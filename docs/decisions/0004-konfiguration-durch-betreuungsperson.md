# ADR 0004: Konfiguration durch eine Betreuungsperson über Web

**Status:** akzeptiert (PI-1), mit Conversational und Haptic abzustimmen

**Kontext:** Ein blinder Nutzer kann eine Webseite nicht wie sehende Personen bedienen.

**Entscheidung:** Eine dritte Person richtet den Roboter über eine Webseite ein. Einstellungen per Sprachbefehl am Roboter sind ein späteres Thema für das Team Conversational.

**Folgen:** Die Seite wird einfach und barrierearm gebaut. Zugriffsschutz ist nötig, sobald Notfallkontakte hinzukommen.
